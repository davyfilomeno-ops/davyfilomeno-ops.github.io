# davyfilomeno-ops.github.io
# Portfolio personnel — Davy Filomeno

## Présentation

Ce projet consiste à créer un portfolio web permettant de présenter mon profil, mon parcours professionnel, mes études, mes compétences et plusieurs projets réalisés pendant ma formation.

Le site est composé de plusieurs pages reliées entre elles :

- une page d’accueil ;
- une page consacrée à mon parcours et à mes études ;
- une page présentant mes projets ;
- une page de contact ;
- un lien permettant de télécharger mon CV.

## Fonctionnement

Le contenu et la structure du site ont été réalisés en HTML. J’ai utilisé des balises sémantiques comme `<header>`, `<nav>`, `<main>`, `<section>` et `<article>` afin d’organiser clairement les différentes parties du portfolio.

Les pages sont reliées grâce à des liens relatifs. Par exemple :

```html
<a href="pages/projets.html">Mes projets</a>
```

Le fichier CSS est connecté aux pages HTML avec la balise suivante :

```html
<link rel="stylesheet" href="../folio.css">
```

## Utilisation de l’intelligence artificielle

J’ai principalement utilisé l’intelligence artificielle pour accélérer la création du CSS, notamment pour la mise en page, les couleurs, les espacements, les animations et l’adaptation du site aux différentes tailles d’écran.

Je comprends néanmoins les principes utilisés. Le CSS fonctionne avec des sélecteurs qui ciblent les balises, les classes ou les identifiants présents dans le HTML. Les classes comme `.carte-projet`, `.retour` ou `.contenu-projet` permettent de modifier individuellement l’apparence de chaque groupe d’éléments.

J’ai également travaillé avec :

- le modèle de boîte : marges, bordures et espacements internes ;
- Flexbox et CSS Grid pour organiser les éléments ;
- les pseudo-classes comme `:hover` pour créer des interactions ;
- les media queries pour adapter l’affichage aux téléphones ;
- les propriétés de couleurs, tailles, ombres et bordures ;
- les chemins relatifs pour relier les pages, les vidéos, les images et le CSS.

J’ai choisi de me concentrer principalement sur la structure HTML, la navigation et l’organisation logique du contenu, tout en utilisant l’IA comme un outil d’accompagnement pour gagner du temps sur la partie graphique.
